# 客户内网验收记录

以下项目必须在实际交付环境执行；本地模拟测试不能自动将它们标记为通过。

| 项目 | 操作 | 合格条件 | 当前状态 |
| --- | --- | --- | --- |
| 干净 Windows | 复制完整便携包，使用普通账户启动 | 不要求 Python、Node、pip 或 npm | 待验收 |
| WebView2 | 准备匹配架构的 Evergreen Standalone Installer | 断外网可安装；不使用联网 Bootstrapper | 提供下载、签名验证与打包脚本；客户安装待验收 |
| 断外网 | 测试终端仅允许内网模型地址，记录出站连接 | 启动、导入、处理、导出不依赖公网 | 待验收 |
| 模型接口 | IT 提供实际 base URL、model、认证方式 | Qwen Code 完成工具调用及多轮回答 | 当前电脑无法访问 |
| Excel 2016 | 打开各场景结果、模板并重算 | 无修复提示，约定格式与数值正确 | 待验收 |
| 业务样本 | 合并、关联、对账、BOM、模板各一组 | 与人工预期逐项一致，异常可定位 | 合成样本已覆盖，客户样本待验收 |
| 取消与失败 | 中断执行、占用输出文件、模拟模型超时 | 不破坏源文件，不误报成功 | 自动化覆盖部分，实机待验收 |
| 易用性 | 业务人员独立完成三类任务 | 无代码操作；记录处理和检查总耗时 | 待试点 |
| 发布 | 归档版本、SHA-256、对应源码、许可证及依赖 | 可追溯、可离线回退 | 构建脚本生成文件哈希 |

生成 Python 默认关闭。只有完成 Windows 受限身份、目录权限、网络和资源限制的越界测试后才可开放；普通进程或模型提示词不是安全隔离。

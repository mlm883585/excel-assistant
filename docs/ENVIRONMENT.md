# 环境检测与离线排障

## 客户使用

在左侧打开“环境检测”。首次打开会检查本机环境、发现已有 Qwen Code，并优先验证外部组合。完整 Agent 检测使用临时合成文件和本机模型模拟服务，不会发送客户数据或连接实际模型。

| 状态 | 处理 |
| --- | --- |
| 已有 CLI 验证通过 | 自动保存该组合；界面显示来源、CLI 与 Node 版本 |
| 已有 CLI 未通过或版本尚未验证 | 查看原因，点击“验证并使用内置版本”，不会修改旧安装 |
| 安装位置未发现 | 点击“手动选择安装目录”，选择 npm 目录或包目录 |
| 已选文件发生变化 | 重新发现、验证并选择；不会静默切换到其他版本 |
| 模型连接未检测 | 保存模型设置后点击测试；只检查最小请求，不代表业务任务已验收 |
| Excel 未安装或测试失败 | 原生重算不可用；常用文件处理继续可用 |
| 数据目录不可写 | 由 IT 检查 EXCEL_ASSISTANT_HOME 或默认数据目录权限、磁盘空间 |

初始兼容列表为 CLI 0.23.3；该版本需要 Node 22 或更高，并须完成实际协议验证。完整离线包包含固定 Node 24.13.0 和 CLI，不要求客户安装 Python 或 Node。模型设置、任务目录与权限由本应用独立管理，不导入客户的全局 Agent 权限配置。

检测支持取消；关闭面板不会中断检测。模型、Excel、Agent 检测超时分别为 15、20、90 秒。任务进行中不能切换运行环境。退出应用会结束检测及其所属进程；不会按进程名称批量关闭 Excel 或 Qwen Code。

## 离线安装

缺少 WebView2 时，启动前的原生窗口可启动随包安装程序；进入应用后也可从环境页面安装。程序必须位于交付目录的 `prerequisites/WebView2StandaloneX64.exe`，且通过交付哈希及微软离线签名校验。可能出现 Windows 权限提示；请在微软安装窗口完成或取消。

安装结束后重新检测。离线签名验证失败、系统阻止运行或权限被拒绝时，由 IT 核对安装介质、系统证书和策略；软件不会在线下载依赖。安装程序运行中关闭环境页面不会终止系统安装。

Python、SDK、Node 或应用文件损坏时，重新解压完整交付目录。不要只复制 EXE。若 EXE 被系统直接阻止、无法启动，应用内检测无法运行，需要 IT 检查完整文件、系统架构和安全软件记录。

## 开发与验收

`python scripts/doctor.py` 复用应用本地检测逻辑，默认不联系模型、不安装软件；`--quick` 跳过组件加载子进程。它输出脱敏 JSON，严重失败时退出码为 1。

修改本地 SDK 后重新执行 `python -m pip install ./vendor/qwen-code-sdk`。构建前会验证 `node_executable` 支持，避免继续使用虚拟环境里的旧版本。前端及后端均需在打包后验证资源路径。

环境报告只导出检查结果，不包括业务文件、完整配置或模型响应。保存到源码目录外，再提供给 IT。真实 WebView2 安装、客户 Qwen、Excel 2016 及断外网网络行为必须在隔离测试环境或客户现场验收；自动化模拟不是这些验收的替代品。

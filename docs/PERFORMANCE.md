# 工作台与完整编辑器性能

更新：2026-09-15。品牌版本复测工作台交互；全量处理及完整编辑器数值沿用 2026-09-14 的整合版基线，本次未重复这些容量测量。以下均为合成数据，不代表客户终端或模型推理性能。

## 测量条件

Windows 11（26200）、Intel Family 6 Model 170、18 个逻辑处理器、31.6 GB 内存，Python 3.13.5、Node 24.13.0。三份 Excel 各 100,000 行、30 列，包含前导零编号、合法 `NA` 文本与数值。预览测量前没有应用索引缓存，未清空操作系统文件缓存；不是隔离硬件跑分。

## 分页预览与全量处理

| 项目 | 整合版结果 | 口径 |
| --- | --- | --- |
| 首批预览 | 0.435 秒 | 独立进程启动并提供首批可读数据 |
| 完整索引及取页 | 25.590 秒 | 包括完整解析和随后 50 次缓存取页 |
| 缓存页后端 P95 | 1.115 毫秒 | 50 次，不含浏览器及 RPC |
| 十万行缓存翻页端到端 P95 | 67.107 毫秒 | 2026-09-15，50 次点击至对应数据进入 DOM，验收上限 500 毫秒；上次为 113.253 毫秒 |
| 普通翻页交互 | 32～49 毫秒 | 2026-09-15，5 次，验收上限 200 毫秒 |
| 三文件合并、导出及完整核对记录 | 204.102 秒 | 输出 300,000 行；包含建立完整结果记录的成本 |
| 读取 / 合并计算 / 导出 | 104.960 / 0.035 / 78.971 秒 | 剩余约 20.136 秒包含差异登记及其他开销 |
| 合并进程树峰值 RSS | 1302.1 MB | 每 50 毫秒采样；不等于整机内存 |

历史参考：引入流式预览前，首屏 27.690 秒、下一页 29.627 秒，均重新读取整表；早期工作台合并耗时 159.516 秒。该阶段没有当前完整候选核对流程，不能直接作为整合版总耗时的同口径基线。完整解析和导出仍有成本，首批预览显示不代表后台工作完成。

## 包体积、生命周期与复现

主入口 JavaScript 约 373 KB，共用 Vue 代码约 135 KB，首屏合计约 508 KB；环境面板按需加载约 13 KB，编辑器按需加载约 5.90 MB（gzip 约 1.65 MB）。这是实际构建体积，编辑器存在大块体积提示；资源与字体均在本地。

历史侧栏每页 30 条、消息最多渲染 200 条，预览每页 50 行并虚拟化宽表列。测试覆盖千条任务、万条事件、300 列宽表、终态停止轮询、设置状态保留及快速切换。反复打开和销毁编辑器的堆内存采样见 [最终验证记录](VALIDATION.md)。

运行 `scripts/benchmark_workbench.py --skip-baseline` 与 `scripts/benchmark_workbook_editor.py` 生成指标。随后运行 `scripts/workbench_ui_smoke.cjs` 测量 50 次端到端翻页。UI 脚本各自启动合成测试服务并在结束后关闭；通过 `PLAYWRIGHT_MODULE` 和 `CHROME_EXECUTABLE` 指定本地测试运行时。报告位于忽略的 `build/`。

浏览器检查 1366×768、1920×1080 及对应约 125%／150% 缩放的可用空间；这不替代 Windows 原生 DPI、客户 Excel 2016 和客户硬件验收。

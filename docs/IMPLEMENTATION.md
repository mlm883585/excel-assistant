# Excel 数据助手实现记录

## 已落地结构

| 层 | 实现 |
| --- | --- |
| 桌面 | PPX V6 源码，Windows 固定 WebView2；应用仅注册自有 RPC |
| 交互 | Vue 3 / TypeScript / Element Plus；任务、文件、表头、分页预览、对话、问题回答、规则与结果 |
| 任务 | SQLite、独立目录、输入副本、后台工作进程、进度、取消、启动恢复 |
| Agent | 官方 Python SDK + Qwen Code 0.23.3；独立配置、会话恢复、权限回调、实际工具输出判定 |
| 工具 | 本地 stdio MCP，文件目录、概况、预览、处理、输出校验 |
| 数据 | DataCraft 核心迁入；合并、关联、清洗、对账、汇总、宽长表和矩阵转换 |
| Excel | 简单模板写入、文本保护、公式缓存检测、单独 Excel COM 实例重算副本 |
| 交付 | PPX PyInstaller 构建、专用 MCP EXE、固定 Node/CLI、许可证与 SHA-256 清单 |

## 与计划的明确边界

生成 Python 仍关闭，未把普通子进程当作安全沙箱。通用数据功能已通过确定性工具提供；模型超出工具能力时会失败并解释限制。Windows 受限执行环境是后续单独验收项。

规则保存使用输入文件槽位，不保存用户原绝对路径。首版支持引用原输入的操作列表；依赖中间输出的规则需要进一步实现输出槽位映射，当前明确拒绝保存。

Excel 原生重算代码已提供，但实际 Excel 2016 与复杂模板未在当前环境验证。公式缓存缺失会阻止将其当作空值处理。简单模板以指定列和起始行填写，不覆盖已有公式。

模型连接设置由客户 IT 提供，客户 Qwen 当前不可达。测试通过本地 HTTP 模拟模型验证真实 CLI、SDK、权限与 MCP 协议，不能据此宣称真实任务的模型成功率。
